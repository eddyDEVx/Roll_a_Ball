# Roll_a_Ball
Jogo sobre uma bola que roda e tem uma aparência do kris do jogo deltarune
**Aluno:** [Edmundo Rodrigues Soares] **
Turma:** [2026.29.09] *
*Feito com:** Unity 6 e C# ##
Sobre o projeto [Um Jogo onde você é Kris deltarune mas versão bola que tem que pegar as Susies que também tem um formato de bola]
## O que o projeto faz - [o jogador movimenta Kris com as setas/WASD] - [ao encostar nas Susies, eles somem e o placar aumenta] 
## O que o projeto contém -**Scripts:** [Coletavel: Faz o coletavel ter adicionar o ponto na pontuação], [CameraFollow: Faz a camera seguir o jogador], [GerenciadorDeJogo: Gerencia os pontos do jogo], [Rotator: Faz o coletavel girar], [PlayerController: Faz o player se mover].
**Objetos principais:** [Bolinha, Plane, os Cubos que são as paredes, PickUp que são os "Paieros" e o "Ibuprofeno"] -
**Recursos usados:** [Rigidbody, Collider com Is Trigger, TextMeshPro, MeshCollider, Material, Textura, MainCamera e DirectionalLigth] ##
Controles - [WASD/setinhas] – [Movimentam o a bola] 
## O que eu aprendi [Aprendi a programar com a unity (um pouco),e utilizar melhor certas ferramentas da Unity .]
